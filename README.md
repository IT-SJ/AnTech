# AnTech
AI를 활용하여 금융뉴스를 요약한 후 시각화하여 사용자에게 제공하는 서비스

## 프로젝트 소개 (은진이 바꾸기)
- ANSight는 Ai를 활용한 금융 뉴스 요약 및 시각화 제공하는 웹사이트 프로젝트이다.

## 개발환경 (예빈)
- 언어 : Java, HTML/CSS/JS
- 서버 : Tomcat Server
- 프레임워크 : Lombok 라이브러리, JDBC, Maven 프로젝트
- DB : MYSQL
- IDE : VSCODE
- API : 한국거래소(KRX) Open API or 금융감독원 Open API (DART)
- 협업툴 : GITHUB
